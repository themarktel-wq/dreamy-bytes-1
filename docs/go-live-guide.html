Go-Live Guide

App ko live karne, roz chalane aur dukandaron ko jorne ka mukammal tareeqa. Is ko shuru se aakhir tak ek dafa follow kar lein.

Short mein: Netlify pe site lagayein → owner number se login → password badlein → sample products hatayein, apne products daalein → phone pe app install kar ke alerts on karein → Shops → Invite shops se dukandaron ko link bhejein → har naye registration ko approve karein.

1 Netlify pe live karna

  1. app.netlify.com pe login karein → Add new site → Import an existing project → GitHub.
  2. Repository dreamy-bytes-1 chunein. Branch: claude/nifty-babbage-4hz8o3 (ya agar code main mein merge kar diya hai to main). Build settings khud aa jayengi; kuch na badlein.
  3. Deploy se pehle Site configuration → Environment variables mein ye daalein:
    Naam (Key)ValueKis liye
    ADMIN_PHONE03036603409Owner ka login number
    ADMIN_PASSWORDKoi mazboot password (6+ characters)Pehli dafa login ke liye
    VAPID_SUBJECTmailto: + aap ki emailPhone notifications (optional, magar behtar hai)
  4. Deploy site dabayein. 1–2 minute mein link mil jayega, jaise lahore-mobile.netlify.app.
  5. Site ka naam: Site configuration → Change site name se lahoremobile jaisa saaf naam rakh lein. Apna domain (jaise lahoremobile.pk) Domain management se lagta hai; HTTPS Netlify khud deta hai.
Zaroori: ADMIN_PASSWORD sirf pehli dafa account banane ke liye hai. Login ke baad app ke andar se password badal lein (Account → Change password). Environment variable baad mein badalne se password nahi badalta.

2 Pehle din ka setup (admin panel)

  1. Login: site kholein → Sign in → owner number aur password.
  2. Password badlein: Account → Change password.
  3. Shop ki details: Settings → naam, phone, WhatsApp (923036603409 format), address, Google Maps link, timings, aur bank/JazzCash/Easypaisa details (checkout pe dikhti hain).
  4. Sign-up ka tareeqa: Settings → Shop sign-up:
    • Shops register themselves, I approve each one: dukandar khud register karta hai, aap approve karte hain (recommended).
    • Only I create accounts: register band. Aap khud Shops → Add shop se account bana kar password WhatsApp karte hain.
  5. Sample products hatayein: Inventory ke upar Remove sample products. Ye wo products hain jo app ke sath try karne ke liye aaye the.
  6. Apne products daalein: ek ek kar ke Inventory → Add product (photo, price, retail price, stock, pack size, minimum order), ya bohat saare ek sath Inventory → Excel sheet se (neeche dekhein).
  7. Home page set karein: App content → banner slides ki photos aur text, highlights, categories, ticker. Save changes dabate hi har phone pe change aa jata hai.

Excel se products (bohat saare ek sath)

  1. Inventory → Excel sheet → Download current sheet. File Excel ya Google Sheets mein kholein.
  2. Har row ek product hai. Columns: sku, name, category, brand, grade, models, price, retail, cost, stock, packSize, moq, reorderLevel, barcode.
  3. Jis row ka SKU pehle se hai, wo product update hoga. Naya ya khali SKU = naya product. Khali cell = purani value wese hi rahegi.
  4. File ko CSV mein save karein (Excel: Save As → CSV UTF-8) aur Import karein. Agar kisi row mein ghalti ho to kuch save nahi hota aur row number bataya jata hai.

3 Apne phone pe app aur alerts

Android (Chrome)

  1. Chrome mein site kholein.
  2. ⋮ menu → Install app / Add to Home screen.
  3. Home screen pe Lahore Mobile ka icon aa jayega.

iPhone (Safari)

  1. Safari mein site kholein.
  2. Share button → Add to Home Screen.
  3. App home screen se hi kholein (notifications sirf aise chalti hain, iOS 16.4+).

Notifications on karein

Admin Dashboard pe Turn on phone alerts ka banner aata hai → Turn on → Allow. Ye har us phone pe karein jis pe owner/staff login hai.

Phir ye alerts aayenge, app band ho tab bhi:

  • Naya shop registration (approve karne ke liye)
  • Password bhoolne ki request
  • Naya order, naya message, claim

App khuli ho to naya order ya registration zyada se zyada 30 second mein screen pe aa jata hai.

4 Dukandaron ko jorna

  1. Shops → Invite shops kholein. Wahan aap ki site ka QR code wala poster hai.
    • Print poster: counter pe lagane ya dukanon pe dene ke liye.
    • Share link on WhatsApp: ready message ke sath link apne WhatsApp groups/contacts mein bhejein.
  2. Dukandar link kholta hai → Register (naam, dukan ka naam, number, market, password).
  3. Aap ko notification aata hai: "New shop is waiting for approval".
  4. Shops ke upar Needs your action box mein Approve ya Reject. Approve hote hi dukandar ko notification jata hai aur usay prices aur ordering khul jati hai.

Dukandar password bhool jaye

  1. Dukandar login page pe Forgot password? dabata hai aur number likhta hai.
  2. Aap ko alert aata hai. Shops → Needs your action → Set new password.
  3. App naya password bana kar WhatsApp kholti hai, message tayyar hota hai. Bas send karein.

Kisi dukan ko band karna ho: dukan ka page → Status: Blocked. Wo foran logout ho jata hai.

6 Backup (har hafte)

Settings → Backup → Save backup se ek file download hoti hai jis mein saare products, dukanein, orders aur suppliers hain. Har hafte ek copy lein aur Google Drive ya email mein rakh lein. Zaroorat pe Restore from backup se wapas laa sakte hain.

7 Updates

  • Products, prices, photos, home page: admin panel se badlein. Ye foran live hota hai, kisi update ki zaroorat nahi.
  • App mein naya feature: naya code GitHub pe jata hai → Netlify khud deploy karta hai → har phone ki app agli dafa khulne pe khud update ho jati hai. Kisi ko dobara install nahi karna.

9 Live karne se pehle aakhri checklist

  1. Netlify pe deploy ho gaya, link khul raha hai
  2. Owner login ho gaya aur password badal diya
  3. Settings mein phone, WhatsApp, address, map, timings, bank details sahi hain
  4. Sample products hata diye, apne asal products aur photos daal diye
  5. App content mein banner aur text apni dukan ke mutabiq kar diye
  6. Owner ke phone pe app install aur alerts on
  7. Khud ek test dukan register kar ke approve kiya, ek test order lagaya, phir test dukan reject/block kar di
  8. Pehla backup download kar liya
  9. Invite poster print aur WhatsApp pe link share kar diya
