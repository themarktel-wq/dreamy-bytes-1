How it works

1. Add each new recurring client with their start date. The app schedules check-ins at day 1, 7, 30, 60 and 90 and gives you a message to send.

2. Log what happens: complaint, reschedule, cleaner change, no reply, price increase, praise.

3. The risk score (0-100) is a simple rule we chose, shown below. Green under 30, amber 30-60, red above 60.

Score rule (a heuristic, not a statistical model): 10 per complaint + 5 per reschedule in the last 30 days + 8 per cleaner change + 6 per unanswered message + 4 per pending price increase - 5 per praise, kept between 0 and 100. Only events from the client's first 90 days count (older events are ignored). Change the weights in the code of this file if you want different ones.

Why these signals? Cleaning-industry blogs commonly cite quality and communication problems as the main reasons clients cancel. That is vendor content with unclear methods, so treat it as a prompt to check in, not as proof.

Data. Stored in this browser only (localStorage). Use Backup JSON or Export CSV regularly. Sample clients are fictional and labelled as sample.
