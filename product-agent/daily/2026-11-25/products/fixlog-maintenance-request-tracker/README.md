# FixLog: Maintenance Request Tracker + Tenant Request Link

A lightweight maintenance tracker for small landlords. Keep every request, vendor, cost and date in one place, send tenants clear status updates, and see each unit's repair history and yearly repair costs. A single file that works offline in your browser, with no subscription.

## What you get
- Units and tenants (name, email, phone)
- Request log: priority (urgent / high / normal / low), status (new, scheduled, in progress, waiting, done), vendor, cost, opened / scheduled / completed dates
- Open-requests list sorted by priority and age, with an "overdue" flag when a request has been open longer than your own limits (editable; the defaults of 2 / 7 / 14 / 30 days are examples, not legal deadlines)
- Message generator: received, scheduled, delayed and completed updates for the tenant, with Copy, Email and WhatsApp buttons
- Tenant request form text: a ready-made list of questions the tenant can answer (problem, location, urgency, entry permission, photos), sent by email or WhatsApp
- Per-unit repair history and a yearly cost summary per unit
- CSV export of all requests, JSON backup and restore, print view
- Saves in your browser (localStorage), works offline, phone friendly
- Sample units and requests are included and labelled "Sample"; use Clear sample data to start fresh

## Important: no tenant web form
FixLog has no server, so there is no hosted request form or link. The "request link" is a pre-filled email or WhatsApp message that tenants reply to. Replies come back to you by email or WhatsApp, and you log them in the tool. Data lives only in your own browser, so export a JSON backup regularly. Clearing your browser data erases it.

## Who it is for
Accidental landlords and small investors (roughly 1 to 20 units) who track repairs in text messages and notebooks.
