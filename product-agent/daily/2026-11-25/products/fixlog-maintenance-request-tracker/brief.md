# Brief: FixLog (d20261125-08)
- Niche: small landlords. Persona: accidental landlord.
- Concept: lightweight request log + tenant message templates + unit history + yearly costs. Software market is crowded with free tiers (Avail, Landlord Studio, Baselane), so the angle is "one file, no account, no per-unit fee".
- Evidence: L3 (Zillow survey via summaries: 92% rank maintenance in top-3 most taxing tasks; Med) and L4 (Avail: only 16.2% of independent landlords use digital tools for maintenance tracking; vendor survey seen via snippet, Low-Med). Do NOT cite the L4 percentage as fact in marketing.
- Deviation/clarification (per plan): no server, so the "tenant link" is a pre-filled mailto/WhatsApp message, stated in README.
- Pitch: stop losing repair requests in text threads; know what each unit costs per year. No outcome claims.
