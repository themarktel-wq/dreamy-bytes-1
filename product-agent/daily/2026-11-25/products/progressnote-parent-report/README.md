# ProgressNote: Parent Progress Report Generator

A single HTML file that turns quick post-lesson notes into a clean monthly progress report for parents. Add each student with their goals, log a lesson in about a minute (topic, a win, what needs more work, homework, and whether it was held, cancelled or a no-show), then pick a month and get a branded report with attendance counts, topics covered, wins, areas to work on, homework set and your own next steps. Print it or save it as a PDF, or copy it as text for a message. Open it in any browser; no install, no account, nothing is uploaded.

**Features**
- Student profiles with parent name, subject and goals
- Fast lesson log: status, topic, win, needs-more-work, homework
- Automatic monthly report: attendance counts, de-duplicated topic list, wins, work areas, homework, next steps
- Your logo, colour and footer line; print / save as PDF; copy as text
- Saved in your browser; JSON backup and restore; works on phone and desktop

**Who it is for:** solo tutors and small tutoring pods who want to keep parents informed without a full tutoring platform.

**Notes:** reports list what happened and contain no scores, grades or predictions. Starting entries are examples. Use Back up before clearing browser data.
