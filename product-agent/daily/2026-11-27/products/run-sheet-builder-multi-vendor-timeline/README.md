# Run Sheet Builder: Multi-Vendor Day-Of Timeline

A single-file tool for wedding and event planners who juggle many vendors on one day. Enter each vendor's arrival, setup time and load-in notes once, and get a master timeline with conflict and buffer warnings plus a printable one-page run sheet for every vendor. Open `index.html` in any browser. No install, no account, no subscription, works offline.

## What you get
- Event details, locations (with how many vendors can work there at once), key moments (ceremony, dinner) and an emergency contacts block.
- Vendor list: role, name, phone, location, arrival time, setup minutes, ready-by time and load-in notes.
- Checks: **conflicts** (more vendors in a location than its capacity at the same time, with the exact time window and names), **tight buffers** (next vendor arrives sooner than your minimum gap after the previous one finishes), **ready-by problems** (setup ends after the time the vendor is needed), arrivals outside the venue's load-in window, and vendors with no arrival time.
- Master timeline: every arrival, setup completion and key moment in time order; copy it as text.
- Run sheets: one printable page per vendor (or all at once) with their times, location, notes, who else is in the same location around their time, key moments and emergency contacts.
- JSON export and import. Data stays in your browser.
- A fictional sample event so you can see it working; remove it with one click.

## Who it is for
Independent wedding and event planners who build timelines in documents and chat and lose time to arrival clashes at the loading dock.

## Good to know
- The checks only know what you enter. Travel time, traffic, elevators, parking and venue rules are not modelled.
- Not a shot-list or guest-flow tool: it is for vendor logistics.
- Tested in Chromium at desktop and 375 px phone width; not tested in Safari or Firefox. Use Export JSON to back up before clearing browser data.
