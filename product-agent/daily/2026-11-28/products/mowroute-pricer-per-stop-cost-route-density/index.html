How MowRoute Pricer works

Cost per hour = labor per person x crew + equipment and fuel + overhead.

Stop cost = (mow minutes + extra minutes + drive minutes to the stop) / 60 x cost per hour + materials. Price needed = stop cost / (1 - target margin), rounded up if you set rounding and never below your minimum.

Margin at current price = (current price - stop cost) / current price. Route revenue per hour = total of current prices / total route hours.

Because drive time is part of every stop's cost, a far-away property needs a higher price than one next door, and dense routes (short drives) earn more per hour.

Honest notes. All starting numbers and sample stops are fictional examples. Vendor guides show example visit prices, but this tool assumes no market price. It ignores taxes, seasonality and weather days. Data is stored in this browser only: use Backup JSON or Export CSV regularly.
